# spark3-vllm-ds41f has moved

This project is now **[christopherowen/spark-ds41f](https://github.com/christopherowen/spark-ds41f)**:
reproducible deployment, tuning and benchmarks for DeepSeek V4.1 Flash on DGX
Spark clusters. Its history, issues and releases moved with it.

To point an existing clone at the new location:

```sh
git remote set-url origin https://github.com/christopherowen/spark-ds41f.git
git fetch origin
```

Links to files under this name no longer resolve; open the same path in
[spark-ds41f](https://github.com/christopherowen/spark-ds41f).
